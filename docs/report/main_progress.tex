\begin{poliabstract}{Abstract}

The baseline system this thesis extends, ``Indeewari,'' lets a non-expert user type a
natural-language question (e.g.\ \emph{``Churches in Verona''}) and receive results retrieved from
a Virtual Knowledge Graph (VKG) via an LLM-driven NL2SPARQL pipeline. This thesis addresses a gap
its own predecessor paper names explicitly as future work: the system answers a question but never
helps the user ask a \emph{better} next one. The goal is a \textbf{query recommender} ---
delivered as a standalone model and API, not a UI feature --- that, after a query is answered,
proposes three follow-up query suggestions conditioned on both the user's stated query history and
their real interaction behavior, since what a user \emph{says} they want and what they
\emph{actually} engage with may differ.

This document reports the project at its current stage of development. The PostgreSQL and Ontop
infrastructure underlying the two evaluation domains is complete and fully Dockerized: separate
containers expose the Movie and Tourism data as independent SPARQL endpoints. The
behavioral-profile component, which analyzes search logs and watch history to identify each user's
stated and actual preferences, is also complete for the Movie domain. Work is currently under way
on embedding-based retrieval, which will use sentence embeddings and cosine similarity to find past
queries semantically related to the current question, even when they use different words. The
next step is to combine the current question, the retrieved similar past queries, and the
behavioral profile so that an LLM can generate candidate follow-up questions; these candidates
will then be validated against the domain schema, ranked, and diversified to select the final
three. Ollama is being used as a local LLM environment for this development. The recommender
core's remaining stages and the thesis evaluation are not yet complete and are not reported here.

\end{poliabstract}
